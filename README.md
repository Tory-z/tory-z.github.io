# 零基础运用trae制作个人简历
作为商科生，为了赛博永生同时方便展示作品集，在从未接触过前端语言情况下通过trae交互式对话简单打造了个人网站简历。

欢迎所有零基础小白fork后通过运用trae打造个人专属简历。
## 文件说明
- 运用trae制作个人网站主要运用了"`index.html`"、"`script.js`"、"`style.css`"三种编程语言。
- 个人网站优化持续更新中，欢迎各位大佬提出优化意见~
